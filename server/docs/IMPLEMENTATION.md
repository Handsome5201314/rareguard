## 模块和事实边界

- src/shared/types.ts：记录、病历段落、授权与摘要类型；validation.ts：入参结构及限额。
- src/server/store.ts：SQLite事实来源、事务、归属、加密记录、版本、人工确认、幂等、授权散列、撤销与scope。
- src/server/files.ts：PDF／PNG／JPEG签名、限额、私有加密原件；文件密文绑定child和attachment。
- src/server/mcp.ts、src/server/mcp-stdio.ts：家庭30工具／旧单患者9工具，HTTP／stdio；重新执行领域授权，不接受模型指定归属。
- src/server/medical.ts：仅汇集当前已确认版本，缺项保持未记录，来源／版本／原件ID保留。
- src/server/http.ts：会话／CSRF／Origin、家长API与静态网页；旧公开评分服务仍无状态。
- web/components.tsx、integrations.tsx：录入、非空病历段落逐项核对、授权管理、摘要。
- schema v3：v1/v2自动迁移家庭授权、档案历史和幂等请求；旧数据与手录幂等兼容。升级前停服完整备份。
