# 公共源码发布记录

2026-10-11 整理首版公共源码，来源为现有 RareGuard App 与服务端工程；在独立发布目录中按源文件白名单复制，不改变运行中的 App 或生产服务。

## 发布范围

保留 Flutter 页面、Android BLE / 本地存储与规则、FastAPI / PostgreSQL / Hermes worker、登录控制台、数据库迁移、合成测试、独立图片资产与构建配置。App 和服务端放在同一仓库，便于队友联调和同步维护接口。

排除真实 `.env`、SSH / API / 登录凭据、配对文件、签名文件、数据库、健康记录、问答和观察文本、设备标识、实测截图、日志、导出、构建产物、缓存、官方 APK / SDK、反编译产物以及本机专用运维脚本。Git 从整理后的源码创建初始历史，不携带原目录的历史。提交作者使用 GitHub noreply 邮箱。

公开业务 hostname 与 App 默认入口依照项目现有行为保留。它们不授予生产访问权限；开发者必须配置自己的测试服务、独立配对与授权。配置模板里的凭据和家庭 ID 全部为空。CI 仅使用临时 PostgreSQL 与合成测试数据，不包含部署凭据。

## 为队友启动做的修正

- 原始初始迁移会提前创建后续 revision 的控制台会话表，导致全新数据库重复建表；发布副本修正 revision 顺序，并加入 fresh-schema 升降级回归。
- 测试只接受显式配置的本机 `rareguard_test` 数据库，禁止沿用业务数据库地址、远程主机或可覆盖连接目标的 query 参数。CI 显式创建独立测试库。
- 本地 helper 读取项目本地配置或显式指定文件，进程环境优先；移除个人路径和特定 Hermes tunnel 地址转换。私有配对输出在 Unix 写入前限制为 `0600`。
- Gradle wrapper 随源码提供；协议检查支持 PowerShell 和 Bash，使用开发者自己的 JDK。专用网关脚本及其测试不属于通用服务源码。
