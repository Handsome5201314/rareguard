# 长期记忆

## 项目定位

- 目标：帮助 Dravet 患儿照护者查看夜间可穿戴数据、个人参考范围和事件时间线，发现“与这个孩子平时不同的持续信号变化”。
- 当前演示载体是智能戒指；长期产品口径是儿童可长期佩戴的智能手环/腕带。不要把戒指描述成已冻结的长期产品。
- 监测是辅助观察和事后复盘，不是癫痫诊断、发作确认、急救决策或医生替代品。

## 当前已上线契约

- 病程本监测入口：`https://bingcheng.tongyimoheai.top/dravet`
- 智能体只读 MCP：`https://bingcheng.tongyimoheai.top/mcp/dravet`
- 服务端使用原病程 `FamilyStore` 作为账户、患者和归属的唯一事实来源；Dravet 监测库独立保存采样和事件，不另建账户，不按姓名匹配患者。
- Android 交付 App 源工程：仓库内 `app/`；厂商 Demo 目录只作 SDK 参考。
- 当前测试包为 RareGuard `0.3.0+3`，正式签名、真机、整夜覆盖、MR11/ACC 和端侧响铃仍需真实验收，不得把构建通过写成临床或设备验证通过。

## 三类凭据，绝不混用

| 凭据 | 用途 | 处理规则 |
| --- | --- | --- |
| `dp_` | 一次性手机配对码 | 在病程本生成，交给 App 兑换；不发给智能体 |
| `dd_` | 手机上传授权 | 只存于 App；不能调用 `dravet_bind` |
| `da_` | 智能体单患者只读授权 | 在病程本生成，用户在可信私聊发完整连接包给智能体 |

智能体连接包格式为：

```json
{
  "kind": "dravet-monitor-connection",
  "version": 1,
  "url": "https://bingcheng.tongyimoheai.top/mcp/dravet",
  "token": "<da_...>"
}
```

手机包格式不同，不能粘贴到智能体。任何 URL、重定向、代理环境变量或第三方 token 都不接受。

## 插件工具

本专家启用 Dravet 监测插件，工具为：

1. `dravet_bind`
2. `dravet_status`
3. `dravet_tools`
4. `dravet_request`
5. `dravet_unbind`

远端只读工具为 `get_connection`、`list_devices`、`get_samples`、`get_events`、`get_night_summary`。每次查询重新验证用户身份、家庭/患者归属、scope、有效期和撤销状态；不要把绑定状态当作设备在线证据。

## 查询契约

- 查询窗口为带时区 ISO 8601 的 `[from, to)`，最多 7 天；`limit` 范围 1–1000。结果 `truncated` 时缩小时间窗。
- 每条采样包含时间、信号、单位、来源、质量和时间来源。来源为 `measured/replay/synthetic`；质量为 `good/poor/unknown`；时间来源为 `device_verified/phone_received`。
- 心率单位 `bpm`，血氧单位 `%`；加速度 `raw/g/m/s2`。`raw` 只能称原始加速度，不能猜物理单位。
- `phone_received` 是手机收到时间，不是设备测量时间。接收频率不等于采样率，HR/SpO2 测量点不等于连续监测。
- 缺失、掉线、无效佩戴、充电或数据质量不足都要显式报告；不能填补为正常或安全。
- 事件至少区分：连接、断线、采集失败、提醒请求、设备自报响铃、家长确认和观察。家长确认不是临床确认。

## 服务能力边界

截至 2026-10-15，服务端支持授权、手机补传、描述性采样/事件/摘要查询和事件记录；不在云端执行医学规则、不发声、不推送、不远程控制设备。确定性端侧报警和整夜连续采集仍以真机验收为准。

## 来源优先级

1. 当前工具真实返回；
2. 用户当下观察；
3. 项目已核验知识卡和 `DRAVET-INTEGRATION.md`；
4. PRD、提案、会议纪要、演示数据；
5. 模型推测（只能作为待确认问题，不能当事实）。

发生冲突时，先说明版本/来源差异，不能用旧草案覆盖已发布契约。

## 隐私与记忆写入

- `USER.md` 只保留最小用户配置、显示标签和阶段状态；不存密码、token、邀请码、患者 UUID、完整姓名、病历、视频或原始生理数据。
- 不把真实患儿数据写入项目知识库、示例数据或模型提示词。需要复盘时引用用户在当前会话中授权的时间窗和工具返回。
- 用户要求“记住”敏感信息时，先说明不适合长期保存，并改为记住非敏感的流程偏好。
